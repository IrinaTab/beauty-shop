# 🛍 Universal E-commerce Boilerplate (BeautyShop)

Универсальный шаблон интернет-магазина, разработанный на современном стеке. Проект создан как портфолио-демонстрация навыков фронтенд-разработки и легко адаптируется под любой бренд за считанные минуты.

## ✨ Особенности

- **Полностью адаптивный дизайн**: От идеального отображения на мобильных устройствах (с бургер-меню) до широких мониторов.
- **Умная архитектура**: Данные товаров, категорий и фильтров вынесены в отдельные справочники (`src/data`). Легко добавлять новые товары.
- **Автоматическая генерация ID и путей к картинкам**: Скрипт в консоли подскажет, как назвать файл изображения для нового товара.
- **Гибкая система стилей**: Цветовая палитра, отступы и размеры шрифтов управляются через CSS-переменные (`variables.css`). Легко перекрасить сайт под новый бренд.
- **Корзина с сохранением**: Данные не теряются при перезагрузке страницы (используется `localStorage`).
- **Микро-взаимодействия**: Плавные анимации модальных окон, выбор количества товара и окна успеха.
- **Интеграция с Telegram (готовый шаблон)**: Настроен Serverless-эндпоинт (`/api/send-order`) для отправки заказов и вопросов в Telegram-бота.

## 🛠 Стек технологий

- **Frontend**: [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Сборка**: [Vite](https://vitejs.dev/)
- **Роутинг**: [React Router v6](https://reactrouter.com/)
- **Стили**: CSS Modules (чистый CSS без препроцессоров)
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Деплой**: Vercel (с поддержкой Serverless Functions)
- **Утилиты**: `clsx` (для объединения классов)

## 🚀 Как запустить локально

1. **Клонируйте репозиторий:**
  ```bash
  git clone https://github.com/ваш-ник/universal-shop.git
  ```
2. **Перейдите в папку проекта:**
  ```bash
  cd universal-shop
  ```

3. **Установите зависимости:**
  ```bash
  npm install
  ```

4. **Запустите сервер разработки:**
  ```bash
  npm run dev
  Откройте http://localhost:5173 в браузере.
  ```


## 🎨 Как адаптировать шаблон под свой бренд

**Цвета и шрифты:** Откройте src/styles/variables.css и измените значения переменных (--accent, --bg-primary, --font-family).

**Товары:** Откройте src/data/products.ts. Добавьте новые объекты в массив rawProducts. В консоли браузера появится подсказка, как назвать картинку и какой ID она получит.

**Картинки:** Положите изображения в папку public/products/ (например, prod_7.jpg).

**Категории и фильтры:** Отредактируйте src/data/dictionaries.ts, добавив свои категории, свойства и теги.

## 📬 Настройка Telegram-бота (опционально)
Создайте бота через @BotFather и получите токен.

Узнайте свой chat_id (через @userinfobot).

В настройках вашего проекта на Vercel добавьте переменные окружения:

TELEGRAM_BOT_TOKEN

TELEGRAM_CHAT_ID

Задеплойте проект. Теперь формы на сайте будут отправлять сообщения вам в Telegram.
